# Monthly B3 reports

Put your consolidated monthly Excel files here.

Expected name pattern:

```text
relatorio-consolidado-mensal-YYYY-mes.xlsx
```

Examples: `...-2026-junho.xlsx`, `...-2026-agosto.xlsx`

Then run:

```bash
uv run python run_all.py
```

These `.xlsx` files are gitignored on purpose (personal financial data).
